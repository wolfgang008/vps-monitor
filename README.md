安装：

```bash
curl -fsSL https://raw.githubusercontent.com/wolfgang008/vps-monitor/main/TG-check-notify.sh | sudo bash
```

更新：

```bash
curl -fsSL https://raw.githubusercontent.com/wolfgang008/vps-monitor/main/TG-check-notify.sh | sudo bash -s -- update
```

卸载：

```bash
sudo vps-monitor uninstall
```
